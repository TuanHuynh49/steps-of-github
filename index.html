Quy trình làm việc nhóm với Git & GitHub

Nhánh feature đã tạo sẵn trên GitHub Web · Đứng tại nhánh riêng pull develop · Code xong push thẳng nhánh mình

⚙️ TÙY CHỈNH THÔNG SỐ (TỰ ĐỘNG CẬP NHẬT TẤT CẢ CÂU LỆNH BÊN DƯỚI)
feature/a feature/b feature/c feature/d
💡 Nguyên lý vận hành thực tế: Leader và nhóm đã tạo sẵn các nhánh feature trên GitHub Web. Thành viên chỉ cần clone code về máy, chuyển sang nhánh riêng của mình đúng 1 lần duy nhất. Hàng ngày khi làm việc: Đứng ngay tại nhánh riêng để kéo code develop và push code thẳng lên nhánh riêng mà không cần phải chuyển đổi qua lại giữa develop!
main: chỉ chứa code hoàn chỉnh, chốt nộp đồ án develop: nhánh tích hợp chung của cả nhóm feature/*: nhánh riêng của từng thành viên (tạo sẵn trên GitHub)

🛠 Xử lý các tình huống thường gặp khi làm việc nhóm

error: failed to push some refs ... [rejected] (fetch first) Nhánh riêng của bạn trên GitHub có commit mới hơn máy của bạn (do bạn hoặc ai đó push từ trước). Hãy chạy lệnh: git pull --rebase origin <tên-nhánh-của-bạn> để tích hợp commit về máy trước khi push lại.
error: cannot pull with rebase: You have unstaged changes Bạn đang có file viết dở chưa commit nên Git chặn không cho pull. Hãy chạy git add . và git commit -m "Lưu tiến độ trước khi pull" rồi mới chạy lại lệnh pull.
error: The following untracked working tree files would be overwritten by checkout: <tệp> Ở máy bạn đang có tệp (ví dụ README.md) chưa commit mà trên nhánh sắp chuyển sang cũng có tệp này. Để tránh mất dữ liệu, hãy xóa tệp ở máy nếu không cần (lệnh: Remove-Item <tệp>) hoặc đổi tên tệp (ví dụ README_backup.md) rồi chạy lại lệnh git switch.
fatal: not a git repository (or any of the parent directories) Terminal đang mở ở sai thư mục. Hãy đảm bảo bạn dùng lệnh cd để đi vào đúng thư mục chứa tệp pom.xml (nơi có thư mục ẩn .git).
Everything up-to-date Tất cả commit ở máy bạn đã được đẩy lên nhánh riêng trên GitHub thành công. Không có gì cần xử lý.
